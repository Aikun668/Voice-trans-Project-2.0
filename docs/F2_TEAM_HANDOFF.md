# F2 局部修音分工

2026-11-09。**Jade 负责清洗训练数据，徐同学负责排查电音，两边现在就能同时做。** Agent 负责把人工切片表接进训练程序、跑工程检查和重训。

上轮训练先从整段录音挑稳定音，漏掉了《心墙》「学」的上拉。后来按手工目标单独修过这个字。Jade 听出更像「学着」，仍有电音。这一版保留作对照，徐同学可以先用它查电音。旧训练权重留作后续对比。

## Jade 清洗现有的 17 段

1. 以原来的手切表 `experiments/F2_TASK2_MIN_EFFORT_PACK_2026-11-05_v001/results/fragments.csv` 为起点。17 段的录音版本、时间和字词沿用。原表、训练目录里的副本和手工试听记录由 Agent 从本地整理交接。
2. 每段核对本人和原唱是不是同一个字，确认这一下是「想修回来」还是「唱法要留」。有分歧的标为待核。比如《心墙》「学着」的 0.785–1.216 秒沿用，已确认修「学」的上拉。「太多」的两份表时间一样，标签有分歧，单独确认。
3. 交一张核准表。每条写清录音版本、本人和原唱的起止秒数、修或保留、修正目标及依据。稳定音可记升降量，字内上滑要记想收回哪一段和目标走势。拿不准的先留在待核清单。

Agent 把训练入口改成按表指定的时间取片段。每条人工标记都要有处理结果，进入训练、用作保留对照，或写明待核原因。先核实「学」的上滑能进入分析，再检查其余条目。按歌曲划分训练和测试，同一首歌的不同版本放在同一组。用训练组已核准的修正样本重训，用留出组对比结果。

## 徐同学独立查电音

先用《心墙》01 对照版的「学」。模型这一步先绕开，直接把现成的手工修正目标给修音程序。本人和原唱的对应片段及手工试听已有记录，可以在 Jade 核数据期间开工。

- [本人录音](../test_dataset/my_singing/rerecord_2026-11-04_f2/wav/心墙01-对照微微跑调.wav)的试听范围为 0.755–1.415 秒，「学」的修音核心约 0.900–1.0615 秒。[原唱分离人声](../test_dataset/my_singing/rerecord_2026-11-04_f2/ref_vocals/心墙_郭静_vocals.wav)的试听范围为 113.905–114.455 秒。时间从各自完整文件开头算。
- 手工试验把「学」往本人音区的 B3 收，保留约五分之一的原上滑。沿用这条试验曲线，复用 [曲线移调](../f2/poc_phase4c.py) 和 [拼接](../f2/poc_phase4b.py)。Agent 负责交接本地试验参数、已有试听和测量。
- 固定录音、切口、修音算法和拼接方式，做「原音·同样响」和三档对照。① 过一遍修音和拼接但变调量设为零。② 用原修正曲线的四分之一幅度。③ 用原修正曲线的全幅度。
- 零变调也听到电音，先分开查声音重建和拼接。小幅自然、原幅有电音，优先查修正幅度和字内变化速度。徐同学交可复跑的步骤、试听和排查结论。

试听集中在这一首，版本写清楚，总时长不超过 10 分钟。按 [路线图的工程要求](ROADMAP.md#82-每个输出文件的工程检查) 核对样本数、削波、实测响度和真峰值、实际音高、浊音重合及源文件哈希后再给 Jade 听。Jade 分别判断有没有更准、有没有电音或跳变。Agent 不能听音，工程测量和听感分开记。

## 最后怎么合起来

Jade 核准样本后，Agent 用新表重训。徐同学把手工给的目标、直接按原唱算的目标、新模型算的目标交给同一个修音程序，用同一批留出片段比较。分别记录目标是否算准、该留的唱法是否被误修、声音是否自然。

原始录音和已有试验只读。新试验另建目录。歌曲范围沿用 [新阶段初步计划](新阶段_前三项任务初步计划.md)。
