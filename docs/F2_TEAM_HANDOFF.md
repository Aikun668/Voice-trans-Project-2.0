# F2 局部修音分工

2026-11-08。下一轮两人并行验证有原唱参考的局部修音，先用《心墙》01「学着」。具体节奏由 Jade 和徐同学一起定。

首轮筛选漏掉了「学」字里的上滑。后来手工修到那一下，Jade 听到更像「学着」，仍有电音。接下来分别验证程序能否找对并算对，以及已知修正目标时能否做出自然的声音。

## 谁负责什么

| 负责人 | 主责 | 首轮交付 |
| --- | --- | --- |
| 徐同学 | 主导音高诊断。核对同字和整体调差，查「学」的上滑在哪一步漏掉，验证该往上还是往下修、应保留的唱法是否被误修。用同一批对照比较模型与直接按参考算音高差的方法。 | 一个可复跑的小实验和一张结果表。由徐同学选验证方法，记录发现、证据和疑问。 |
| Jade | 定样本和听感标准。先标一处故意唱偏且希望修回的片段，以及一处希望保留的唱法。用原音和已有字感改善版做参照，决定后续优先排查哪个处理因素。 | 两处带时间范围的标记。试听分别判断「有没有更准」「有没有电音或跳变」。 |
| Agent | 准备交接输入和复跑入口。与 Jade 确定对照变量后制作等响试听，回读实际移调，检查样本数、削波、实测响度与真峰值、音高与浊音重合及源文件哈希。 | 工程检查和实验记录。Agent 不能听音，听感结果由 Jade 给出。 |

## 徐同学可以先做什么

1. **先查《心墙》「学着」。** 以完整文件开头为时间零点，[本人 01 对照版](../test_dataset/my_singing/rerecord_2026-11-04_f2/wav/心墙01-对照微微跑调.wav)约 0.76–1.42 秒，[原唱分离人声](../test_dataset/my_singing/rerecord_2026-11-04_f2/ref_vocals/心墙_郭静_vocals.wav)约 113.90–114.46 秒。看「学」约 0.89–1.08 秒的音高变化，对照 [音高分段](../f2/poc_phase2.py)和 [稳定音筛选](../f2/self_ref_align.py)中的 `notes_of()`，记录它有没有进候选、为什么。用前后能确认的对应音校准两边的调差，再估计「学」里需要改的部分。
2. **用已知偏移检查方向和幅度。** 本地已有《莫问归期》02 同一录音的受控对照，4.272–5.422 秒人为抬高约半音，预期修正约 −100 音分。已有单例中，模型估 −95.4，直接按参考算差约 −98.4。Jade 和 Agent 另行交接这份实验的输入、脚本和版本记录。拿到后复跑，再加一处应保持的对照，分别记录漏修和误修。
3. **把结果放在一张表。** 每行写录音版本、字及起止秒数、希望修或希望保留、参考位置、预期方向和幅度、模型输出、实际回读及跳过原因。对字内上滑可以附音高曲线。待确认的参考位置标为待确认。

## 两边怎么汇合

- 两边可以同时开工。徐同学先检查远程已有录音和代码，Jade 先定两处标记。用同一处「学」交换结果。
- 漏检或方向有误就先定位分段、对齐、目标计算或预测。实际移调达到设定值但仍有电音，就固定输入，一次只改一个因素，排查修正曲线或声音合成。工程测量和听感分别记。
- 用留出的素材比较模型和参考音高差基线后，再决定补录或重训。原始录音只读，实验另建目录。下一轮试听仍集中在一首歌。

长期建议由徐同学主责 F2 算法和评测，Jade 主责 F1 力度与两条线的听感验收。长期安排由两人再确认。

素材范围和早期对齐流程沿用 [新阶段初步计划](新阶段_前三项任务初步计划.md)。
