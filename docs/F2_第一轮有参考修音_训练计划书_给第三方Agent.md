## 0. 一句话任务

对 **唯一一处「希望修」**——《离开我的依赖》01 轻度跑调里的 **「当你」**——做出**修前／修后可听音频**，并留下可复查的实验记录；**故意**区间必须保护、不得乱改；**心墙**整首不参与「学习／调参／拟合」；严重档不碰。

第一轮成功标准（Jade 已拍板）：**跑通到出音频 + 有记录**；听感细抠（自然度／电感／像不像本人）放到下一轮，本轮不过度优化听感。

## 5. 方法选择（可选，但必须可复查）

Jade 拍板：**方法可选，必须留记录。** 推荐优先级（不是强制唯一）：

1. **局部音高修正（土办法）**：在希望修窗内，按参考 F0（或参考音高轨迹）修正本人 F0，再合成／拼接回原干声；窗外原样。CPU 通常够用。
2. **现成开源修音／变调工具链**：只要满足「只动窗内、保音色、可脚本化、可记录版本」。
3. **小模型／微调**：仅当执行方环境有 GPU 或可接受极慢 CPU，且仍 **只服务这一处希望修的出声**，不得借机改划分或扩大标注需求。须在记录里写清模型名、权重来源、许可、命令。

**明确禁止：**

- 把原唱者声音直接叠进输出冒充「修好了」
- 为凑效果改故意段、严重档、心墙
- 改写 `逐字候选_*.csv` 原文件
- 无记录的「我训了一下」口头结果

仓内可参考、**不是本轮必用训练入口**的现有代码：

- `f2/` 对齐与 PoC 脚本
- `neuralsvb_f1/`：NeuralSVB **推理封装**，README 写明无训练；若用须自备官方训练／权重并记许可（GPL-3.0 等）
- `f1_adaptive_v0/`：DSP 思路可参考，勿把 F1 力度目标偷换成本轮主线

## 7. 执行步骤（给第三方 Agent 的作业顺序）

1. **拉仓／定位文件**：确认本人 WAV、参考人声、`fragments.csv` 存在；计算 SHA-256 写入 manifest。
2. **冻结范围**：只允许改 fragment id=5 窗；复制故意行为 `protection_intentional.csv`。
3. **选方法并写 `method.md`**：在动手前写清；中途换方法必须追加一节「变更说明」，不得默默换。
4. **实现并跑通**：产出修后音频；窗外应与输入一致（允许重采样导致的整体重写，但须在 report 说明，且故意段听感／音高曲线不应被「修好」）。
5. **保护检查**：至少 2 处故意对照或自动检查写入 report。
6. **写 README**：大白话三节——做了什么、怎么听、明确没做什么。
7. **提交**：能推仓则开 PR 到原分支策略允许的目标；不能则打包整个 `experiments/F2_ROUND1_...` 目录交 Jade。
8. **停**：不要自动开第二轮大模型微调；不要扩大希望修列表。
