# 新阶段初步计划：素材、跑调标记和时间对齐

日期：2026-11-05。Jade 已认可当前初步分工；徐同学尚需结合自己的时间和基础讨论，具体节奏由两人商量。本计划用于安排前三项工作，完成情况持续写入开发日志。

## 共同目标和范围

先从有原唱参考的局部跑调修正入手，为后续小数据训练准备可靠素材。只处理《心墙》《离开我的依赖》《莫问归期》的重录清唱和对应原唱；排除严重跑调版本及凤凰传奇旧素材。本人“对照微微跑调”不是完美标准，原唱也不能直接视为绝对标准。训练方式、训练数据量和最终效果均待后续验证。

原始素材只读；分析结果另存。不能听音的 Agent 只做整理、测量和辅助定位，不能代替 Jade 判断唱法与听感。

## 任务一：盘点和选择素材

**目标：**弄清三首歌有哪些录音和原唱，整理出可供后续核对的清单。

1. 列出本人录音和对应原唱，排除严重跑调和凤凰传奇旧素材。
2. 检查时长、格式及文件能否读取。
3. 找到本人录音可能对应的原唱句子，请 Jade 确认是不是同一句。
4. 整理并核对歌词；本人和原唱若有不同，分别记录实际唱出的字，包括漏字、重复或不同唱法。
5. 记录已确认、待确认及有问题的素材。

**分工：**

- **Jade：**确认同一句，核对两边实际歌词。
- **徐同学：**熟悉素材和文件结构，独立检查一首歌的录音信息，记录发现的问题。
- **Agent：**盘点文件、检查时长和格式、寻找候选位置、整理清单和歌词候选。

**交付：**素材清单及核对过的歌词。当前已检查三首的 10 段非严重档本人 WAV 和 3 首原唱人声；《心墙》对照微微跑调版与原唱候选已由 Jade 确认唱同一句，其他版本和逐字位置仍需分别核对。

## 任务二：找出需要修的地方

**目标：**找出值得研究的片段，区分希望修正的跑调和应保留的唱法。

1. 从一首歌的轻度跑调录音开始，查看音高变化，找出可能唱偏的位置。
2. 整理带前后内容的短片段，供 Jade 判断。
3. Jade 标记“希望修”“故意这样唱”“拿不准”或“不需要修”，并可补充说明。
4. 将判断与录音、时间位置、对应字及备注记录在片段清单中。
5. 保留无需修正的片段，再逐步扩展到另外两首。

**分工：**

- **Jade：**主导唱法判断和标注口径，借鉴已有数据标注经验，确认记录方式是否好用。
- **徐同学：**独立研究现有音高分析工具，分析一段录音，提交候选位置、判断理由及不确定点；用反馈复盘自己的判断。
- **Agent：**协助准备片段和简单的确认方式，整理判断并检查程序输出。

**交付：**片段清单及徐同学的一次音高分析记录。音高曲线和自动候选只能辅助判断，不直接代表已确认跑调或可靠训练标签。

## 任务三：对齐本人录音和原唱

**目标：**记录两边同一句、同一个字各自出现的时间，为后续样本整理提供依据。

1. 使用分别核对过的本人歌词和原唱歌词。
2. Jade 在本机使用 `D:\My_Grand_Projects2026\Videos-Master-Project\Qwen3-ForcedAligner-0.6B`，分别处理本人录音和原唱候选片段，生成逐字时间戳。
3. 根据实际歌词匹配同一个字，记录两边的时间；录音存在重复、缺字或不同唱法时不强行配对。
4. 抽查时间点是否落在实际唱到的字上。Qwen 输出仍需抽查；异常或拿不准的片段先标记，不直接当作训练样本。
5. 对照任务二的标记，查看希望修的地方在原唱里对应哪里，并记录尚未解决的问题。

**分工：**

- **Jade：**在自己的电脑运行 Qwen，抽听结果并确认疑难歌词和唱法。
- **徐同学：**接收已导出的时间表，独立检查相同字是否对应、时间顺序是否合理，找出异常并提出排查方法；不依赖本机安装该模型。
- **Agent：**协助准备输入、汇总时间表、准备抽查清单并整理异常。

**交付：**逐字对照表，至少包含歌曲、录音版本、字、本人起止时间、原唱起止时间和状态。注明时间是相对于完整文件还是截取片段、片段在原文件中的起点，以及来源和模型运行信息，避免两人交换时错位。

Jade 已用《心墙》一段本人录音和原唱候选试验本地 Qwen，并抽查多个字，反馈时间点很准。这支持把它作为辅助工具，不代表三首歌的所有输出都已验证。

## 并行与交接：避免互相等待

| 如果还没有拿到…… | 另一方先做什么 | 什么时候交接 |
|---|---|---|
| Jade 还没核对完全部歌词或运行 Qwen | 徐同学先用已有原始录音学习文件读取与音高曲线，分析候选位置、记录理由；Agent 同时整理歌词候选。 | Jade 先交付一小段已确认歌词和时间表，不必等三首全部做完。 |
| 徐同学的分析或异常检查还没完成 | Jade 继续核对下一段歌词、按歌曲运行 Qwen 并抽查；Agent 整理已有结果。 | 徐同学先交付一段分析或一批异常，不必等整首歌完成。 |
| 有人还没判断某处是不是跑调或同一个字 | 先标“待确认”，继续处理其他清楚的片段；徐同学可先排查音高或时间顺序。 | 集中整理少量问题，一次交给 Jade 听；不能确认的保持待确认。 |
| 两人还没选出训练与测试歌曲 | 两人可以先盘点、分析和核对三首；材料只作候选。 | 真正训练之前共同确定按歌曲划分，避免同歌不同版本混入训练和测试。 |

每次交接至少带上歌曲和录音版本、时间范围及时间基准、歌词或字、状态、文件路径和待解决问题。徐同学需要先确认能访问这三首源文件；若本机没有，先与 Jade 协商共享副本和存放位置，等待期间可阅读已有 F2 记录和分析流程。Qwen 权重无需作为交接文件。

以上安排让两人有可并行推进的工作，但最终确认歌词、唱法和可靠对齐仍依赖必要的人工判断；不能把“待确认”当作已完成，也不保证任何阶段都完全没有等待。
