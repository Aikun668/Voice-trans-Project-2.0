# 这次项目怎么分

最新实验在 MusicBERT 次线，主线关系保持原样。现在分四块：

| 分区 | 放什么 | 当前情况 |
|---|---|---|
| 主线 | 用公开配对数据探索无参考修音，以及已经做过的试训和反馈 | 首次试训被你判为没有有用改善。失败版留下作对照，下一步方案未定。 |
| 次线 | MusicBERT（学过音符规律的模型）现成权重加适配的独立试验 | 已跑通，没微调；工程合格，预先定的效果门槛没过，等你的听感反馈。 |
| 共用资料 | 原始录音、PopBuTFy 清洗结果、17 对确认切口、仍被调用的代码和来源登记 | 两条线按需引用。17 对不用重标；原唱秒数必须跟着当时那份文件的指纹走。 |
| 历史记录 | 固定算法调试、旧有参考修音、过时计划和试听 | 已退出当前待办，原位归档。保留失败原因与可复用部分。 |

改了主目录和两个旧工作树的入口，统一从主项目 [ROADMAP](ROADMAP.md) 看当前方向，从 [文件索引](FILE_INDEX.md) 找资料。旧交接里让你再清洗17段的任务也标明已经完成；同学的独立排查是否完成仍保留待核实。

没有整批搬实验目录，因为一些旧文件还在被代码调用。采用“改入口、标历史、留原位”的归档方式，避免把依赖弄断。模型、音频、确认表和环境都保留；目前没有已验收的正式默认修音模型。

逐目录分类、17对来源登记和建议落实表在[本轮整理记录](../experiments/F2_PROJECT_ORGANIZATION_2026-11-14_v001/REPORT.md)。本说明只讲怎么整理，现行路线仍以 ROADMAP 为准。
