# F1 可听验收标准与未通过处理

> **2026-11-03：本文件为历史记录，现行路线与规则见 [docs/ROADMAP.md](ROADMAP.md) 与根目录 AGENTS.md。**

用途：每次生成音频前，先让 Jade 知道“这次要听什么”。这是项目内的验收约定，不是通用声学评分标准。
本表用于后续实验；S1 第一次反馈保持原样，不用新增标准追改旧结果。

## 一、先确定该不该处理

- 每轮先登记：哪个听感问题、哪条本人素材、哪个片段、预期一句话、不可接受的副作用。
- 不能因为项目有 Distortion、EQ 或 Compressor，就默认录音需要它。
- 若原音没有相应问题，标记“不适用／无需处理”，不强行制造差异，也不以此认定所有方案无效。
- Jade 无须描述频率、阈值或专业原因；可以直接选择下面的日常听感句子。
- 若连原音问题都未确认，先做需求/样例对齐，不直接产出更多候选。

## 二、每个维度听到什么算改善

| 功能 | 原音需先确认的问题 | 可以算改善的听感 | 不能接受的变化 |
|---|---|---|---|
| S1 饱满度／厚实感 | 自己觉得单薄、空、不够充实 | 元音和整句更充实，但每个字仍清楚、轻重还在；正常试听就更愿意听处理版 | 闷、糊、轰、毛、硬、被压住；只变响或只变暗不算 |
| S2a 清晰／通透 | 某段歌词费劲才听清，声音浑浊或有遮挡感 | 不必更大声，就更容易辨认那几个字；声音舒展，仍有厚度 | 尖、薄、齿音突出、疲劳；只是更亮不自动算好 |
| S2b 柔和／刺耳控制 | 某个字或音确实扎耳，需要先定位 | 那几个扎耳的瞬间更舒服，其余字音仍清楚、通透 | 整句像蒙住、闷掉或尾音消失；只是整体变暗不算 |
| S3 齿音 | “丝／是”等辅音明显抢耳 | 这些辅音不再突兀，歌词中的辅音仍完整、能听清 | 像漏字、大舌头、含混，或元音也受损 |
| S4 大小声／动态 | 某个字突然冲出来，或轻字缩回去难听清 | 大声不突然顶耳，轻字更易听清，仍分得出轻唱与用力唱 | 每个字一样重、情绪消失、抽吸、呼吸或底噪明显突出 |

上述维度会相互影响；先只验证一项，其他处理旁路。最终悦耳度是综合结果，不是独立旋钮。

## 三、单素材通过条件

三个条件必须同时满足：

1. **目标改善能被 Jade 感知**：固定试听音量、匹配响度，正常听一两遍就能形成偏好；不要求反复找区别。这里的一两遍是减轻负担的工作约定，不是统计听测结论。
2. **愿意选处理版**：听得出变化不等于喜欢；非常认真才辨认出一点差别，只记“收益不明确”。
3. **没有不可接受的副作用**：字清楚、情绪起伏还在、仍像本人，无明显闷糊、刺耳或失真。

全部满足只记“本条素材暂通过”，另一条本人录音复验后才决定是否保留。不能代表所有歌手都适用。
工程技术检查另外记录，不替代以上三项。不得用 dB、谐波增加或测试通过替 Jade 作出质量判断。

## 四、结果与下一动作

| Jade 的反馈 | 记录状态 | 下一动作 |
|---|---|---|
| 没有这个原音问题 | not_applicable | 本素材旁路，不为开启模块而处理 |
| 明确更好，且自然 | provisional_pass | 保存设置，换另一条本人录音复验；复验通过后才组合 |
| 更好，但副作用需收回 | beneficial_with_side_effect | 留住有效基准，只改同模块一个控制量，最多修订一次 |
| 能辨认变化，但不更好 | changed_not_better | 不通过；有明确修订假设才试一次，否则暂停候选 |
| 无区别，或非常认真才一点差别 | no_clear_benefit | 核查文件/播放/响度；有依据最多修订一次，仍无收益就暂停或更换 |
| 明显闷糊、失真或不像本人 | unacceptable_side_effect | 该档拒绝，不进入组合；没有正向基准时不默认用其他效果补救 |
| 工程检查失败 | technical_blocked | 先定位技术问题，不交给 Jade 作听感验收 |

“最多一次修订”是上限，不是必须用掉的次数。无正向证据时可以直接暂停；不得把候选暂停等同于整个 F1 功能失败。

## 五、这轮 S1 怎么办

- 已知：温和档收益不明确；较明显档明显闷、略糊；没有可接受基准。
- 当前决策：此 Distortion 候选不进入组合，建议暂停；保留音频、配置、原话和测量证据。没有生成新修订音频。
- 额外发现：此前没有先确认本人素材存在明确“单薄”的问题。下一实验必须先补目标片段与预期听感卡。
- 下一关是“候选适配筛选”，不是继续加 drive：须能说明模块如何解决已确认问题，优先有歌声示例/操作流程，且能独立输入输出并保留原声。
- 找到更合适的候选才做单项小样；找不到则将 S1 记为“当前未解决”，经讨论后再选其他确有问题的维度。不能为了进度硬凑通过。
- 不自动进入 S2，不从零写新算法，不要求 Jade 学专业调音来补足选型。
