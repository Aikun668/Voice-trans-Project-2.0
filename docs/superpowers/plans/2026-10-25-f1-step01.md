> **For agentic workers:** Use superpowers:executing-plans in this session. The user authorized the rules, feature map and first small listening delivery; no further implementation confirmation is needed. Do not implement later nodes before listening feedback.

**Goal:** 复用 Pedalboard Distortion，适配本人录音输入电平，给 Jade 一个独立 S1 试听。
**Architecture:** 现成模块负责非线性声音处理；薄适配层只负责电平、增益补偿和混合。现有 WAV/响度/诊断函数负责产物检查，新目录交付。
**Tech Stack:** 独立 .venv-f1（复用已有 NumPy/SciPy），固定 Pedalboard 版本，FFmpeg。
**Spec:** ../../F1_FEATURE_MAP.md 与根目录 AGENTS.md。

## Global Constraints

- 保留本人音色，不主动改音高或节奏；不叠加 EQ、压缩、去齿音、降噪或混响。
- 原音不动，输出目录必须是新的；保留现有未提交改动。不自动提交其他工作的文件。
- 主素材只用 shige_medium.wav，交付三条完整 WAV 与明确标记的短句对照。
- 原音混合前先补偿处理电平，最终按共同 LUFS 与真峰值余量校准。
- 所有听感结果保持 pending_jade；最多一次针对性修订后停止该候选。

## Review Focus

- 不同输入音量经适配后，同一配置的相对非线性程度应该接近。
- 完全旁路应保持输入；静音不能触发无穷增益。
- 处理必须产生可测的新谐波，不能只是整体增益。
- 采样率、时长、极性与有效样本不得意外改变；削波、非有限值、响度偏差须拦截。
- 主观上的温暖与失真需要 Jade 判断；有新谐波不等于质量变好。
