### 2026-11-05 · 吸收调研结论：粗对齐 + 筛错标签 + 少量人工

Jade 认可调研判断：现阶段不追求永不出错的对齐模型；优先自动发现并筛除错误标签。吸收 GTSinger / WhisperX / 歌声专用对齐的组合思想：

1. 先核对歌词与音频是否对应（任务一未完项）。
2. Qwen 只做粗对齐，给出大部分字的时间候选。
3. 零时长、明显漂移的字交给 MFA / HubertFA 复查（或标异常）；仍不能确认的标不可用，少量人工修正。
4. 只把核对可靠的数据进后续样本/训练。
5. **字对齐**与**音高轨迹对齐**分开验证：字对齐解决「唱到哪句话/哪个字」；音高分析（任务二，徐同学）解决「对应哪个音符 / 要不要修」。

执行口径改为：**粗对齐流水线 + 人工抽查坏点**，不是继续死磕单一对齐器。
