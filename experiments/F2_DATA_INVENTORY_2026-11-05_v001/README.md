# 新阶段素材盘点 · 2026-11-05

范围：只使用《心墙》《离开我的依赖》《莫问归期》的重录清唱，排除严重跑调和凤凰传奇旧素材。每首的“对照微微跑调”并非完美标准。

`inventory_run.py` 只读 10 段非严重档 WAV 和 3 首原唱分离人声，记录文件头、采样峰值和 SHA-256，读前后哈希一致；`results/inventory.json` 是检查结果。无修音。核对页的两段 WAV 以内嵌 Base64 放在 HTML 中，侧边栏预览无需读取本地路径或旁边的音频文件。

《心墙》使用仓库 `f2/poc_phase4_realign.py` 的 `cost_matrix`、`subseq_dtw`，Praat 提取音高，0.1 秒步长、100 音分粗网格，仅定位原唱候选：对照版约 112.8–121.1 秒，轻度版约 113.4–123.2 秒。由于歌曲旋律可能重复且唱法、音区不同，候选不是已核实歌词对齐或目标标签。`index.html` 只请求 Jade 核对对照版候选，引用原 WAV 直接播放；不是处理版试听，也没有生成音频或等响。Agent 不能听音。

后续在收到该句反馈后再判断是否可用、是否还需核对轻度版，并逐首继续。不预设测试歌或把候选标为真实跑调。

核验：页面改用内嵌音频数据，避免侧边栏预览读取本地文件；Agent 不能听音，实际听感仍由 Jade 确认。
