# F1-EXP-004：P3A 谐波饱和单模块验证

日期：2026-10-31。状态：pending_jade。

## 目的

EQ 单独优化已暂停：+4/+8 dB 可改变亮度/清晰度，但无稳定饱满度改善，且 A05/B01 出现非单调强度反馈。本轮转向 Soft Saturation，只验证谐波饱和单模块，不叠加 EQ/压缩/其他美化。

## 样本

A01、A05。Holdout 未处理；不启动模型训练。

## 实现

- Soft tanh：`tanh(drive * x) / drive`，小信号近似线性、峰值软压缩。
- 4x oversampling；20 kHz 低通后下采样，降低混叠风险。
- Wet/Dry = 0.5（参数可调，本轮固定以只比较强度）。
- Light/Medium/Strong：drive = 1.5 / 3.0 / 6.0。
- 处理前后保持长度与时间对齐；试听版等响，A/B/C 随机隐藏强度。

## 评价

饱满度是否提升；是否只是更亮/更响；是否自然、像原歌手；是否刺耳、沙哑或失真。

## 边界

本轮不实现 EQ+饱和组合；不实现并行压缩；不碰 Holdout；不训练/部署模型。
