# 《我们的歌》薄音版 · 第 6 轮

工程 technical_pass；听感 pending_jade。Agent 不能听音，测量不能证明音质改善。P0 继续，不做老师 demo。

第 5 轮③听得出但仍空，有不稳定带电；④空旷似乎少一点，约 11–12 秒有电和波动。完整原话在上一轮 feedback 与 ROADMAP §11。

诊断：在 v005 ④的 11–12 秒，衰减段的预母带增益在 0 至 −10 dB 间变化，相邻 5 毫秒至少变化 1 dB 的次数为 34。时间吻合只是线索，不能证明电音成因；升调、补谐波、母带或原音也可能有贡献。③和④共用升调与补谐波；本轮取消额外宽架，只对④做一次针对性修订，并提供只升调定位对照。

| 试听页 | 处理与目的 |
|---|---|
| ① 原音·同样响 | v005 原音锚点，增益和限幅 |
| ② 上次有力那版 | v005 ② 原文件，升 310 音分 + 原有补谐波 + 母带 |
| ③ 只升调·定位对照 | 同一 +310 音分，旁路补谐波，母带；与②比较以定位共用链中的潜在贡献 |
| ④ 有力版·缓和字尾 | ②的预母带基础上，衰减段目标 −6 dB，120 ms 高斯平滑，再母带；针对 v005 ④波动做一次修订 |

④ 11–12 秒的控制增益范围 −2.16 至 −0.62 dB，相邻 5 ms 变化达 1 dB 的次数为 0。字尾指标相对原音为 +0.95 dB（②为 +2.13 dB；v005 ④为 −5.82 dB），所以修订后字尾削减也明显减弱；不保证能减轻空旷。字尾控制是全频相同的时间增益，会同时改变 250 Hz 以下与以上的瞬时音量；没有对低频单独均衡衰减或高通。没有混响、双叠、硬吸附、谐波激励或额外谐波宽架。整体升调是独立 F2-K，本轮②③④打开，产品默认关闭；F1 不改音高。

四个文件各 669696 样本、48000 Hz、无削波或 NaN；FFmpeg ebur128 实测均为 −13.1 LUFS / −1.3 dBTP。音高中位相对原音分别为 0、+310.53、+310.34、+310.54 音分；浊音重合分别 1.000、0.997、0.997、0.997。④相对未做字尾控制的补谐波输入，音高中位变化 0 音分、浊音重合 0.9887。齿音、句间底噪和每个文件哈希见 report.json。源 SHA-256 处理前后不变。v001 的补谐波原始文件经母带后与 v005 ②相关 0.999999999，确认输入谱系。
