# F1-EXP-020 结果（pending_jade）

F1-P6 第一共振峰位置调整：基线 EXP-016 M2（X1+M2，原样引用），在其上只加上移 +20Hz / +45Hz。方法为 LPC 极点旋转（保持极点模长 ⇒ 带宽不变，只改角度 ⇒ 频率上移），包络增益施加于 STFT 幅度谱，相位保留。

## 技术检查

| 项 | S20 | S45 |

| 目标位移 | +20 Hz | +45 Hz |
| **实测位移** | **+25.1 Hz** | **+59.6 Hz** |

| 统一响度 | −19.97 LUFS | −19.97 LUFS |

- 共振峰**可可靠修改**：两档实测位移均落地，F0 与时长完全保持。
- 实测位移略超目标（+5.1 / +14.6Hz），在容差内（容差 8 / 15.75Hz）。

## 重要发现（超出预期，必须记录）

**基线 X1+M2 的 F1 已从原音的 226.9Hz 被推到 269.7Hz（+42.8Hz）。**

原因是 M2 的包络移植以 A02（正常版）为目标，而 A02 的 F1 = 287Hz——**包络移植顺带把共振峰位置也搬过来了**。因此本轮两档的**相对原音总位移**为：

- S20：**+68.0 Hz**（226.9 → 294.9），已略微超过 A02 的 287Hz；
- S45：**+102.5 Hz**（226.9 → 329.4），远超 A02。

也就是说，名义上的"小幅度验证"实际是在**已经偏高 43Hz 的基础上再加 25/60Hz**，两档可能都属"过度上移"。**这不是本轮做错，而是此前 M2 的隐性副作用在本次被显影。**

## 判定含义

- 若 S20（总 +68Hz）听感变差（变尖/变字/不像本人）→ 说明 F1 已在正常范围内，本方向无空间；
- 若 S20 听感无明显变化 → 说明 F1 位置本身不是"厚"的感知关键，M2 那 43Hz 的上移也贡献甚微；
- 若 S45（总 +102.5Hz）出现明显变字/失真 → 确认 F1 位移存在硬上限，但该上限是实测得到的，可作为后续边界依据。

## 关于"力度感"的范围归属（本次分析结论）

项目文档明文：F2 = 音高修正；"音高修正、节奏、混响、人声分离、伴奏：不借美化名义混入 F1"。

按声学构成拆解"发声力度感"：

| 物理成分 | 归属 | 本项目状态 |
|---|---|---|
| **F0（整体音高）** | **F2 修音** | **F1 管不到（用户判断正确）** |
| 整体 SPL / 响度 | 被响度统一主动抹平 | 为公平比较必须抹 |
| H1−H2（声门闭合） | F1 | 已做（−4dB），可辨但弱 |
| 频谱倾斜 | F1 | 已做（M2） |
| F1 位置 | F1 | **本轮已做，最大档被接受** |
| 起音陡度 / 瞬态冲击 / crest | **F1（S4 动态）** | **从未做对方向** |
| F1 带宽 / HNR·CPP | F1 | 未做 |

**关键结论：力度感并非全部属于 F2。约一半（瞬态/冲击/周期性）仍在 F1 范围内，且此前唯一试过的动态处理是"压缩"——方向与"提升力度感"相反。** 压缩减小动态对比，会让声音更平、更没冲击；从未试过相反方向（动态扩展 / 瞬态增强）。
