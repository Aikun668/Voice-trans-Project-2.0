# AI 歌声美化与修音

输入清唱人声，探索让歌声更有力、自然，并改善音准，同时保留本人音色、咬字和演唱表现。

当前 F1 固定算法调试已暂停。下一阶段计划盘点本人试唱素材，准备小范围数据，探索训练或微调较小模型。F2 围绕自然音高修正继续研究。实际模型、训练数据和两人分工仍需讨论。

实验新建 `experiments/<主题>_<日期>_vNNN/`，保留代码、报告、试听材料和反馈。新阶段可按主题和日期区分目录。原始素材和既有实验输出只读，保留原来的位置。模型数据集、权重和训练输出的目录结构在方案确定后再定。

技术检查和实际听感分开记录。Agent 无法听音，由本人或试听者作听感判断。F1 不主动改音高，整体升降调由独立的 F2-K 开关控制。
