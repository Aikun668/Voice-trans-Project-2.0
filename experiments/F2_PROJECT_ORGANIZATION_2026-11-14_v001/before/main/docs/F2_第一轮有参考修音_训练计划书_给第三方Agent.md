## 1. 目标与边界

- 本轮只求流程第一次完整走通：**数据 → 训练 → 测试 → Jade 试听 → 反馈记录**。不追求模型聪明，不预设效果。
- 只处理《心墙》《离开我的依赖》《莫问归期》的**非严重档**录音（10 段 WAV）和 3 首原唱分离人声。严重跑调 5 段与凤凰传奇旧素材不碰。
- 不改节奏、不改时长；整体升/降调（F2-K）不参与本轮。
- 合成必须复用可信代码（f2/poc_phase4b.py / poc_phase4c.py 的拼接修正）。模型只决定"修哪里、修多少"，Agent 不新写 DSP 合成。

## 3. 分步计划

每步写明：输入 / 输出 / 谁做 / 完成标准。产物一律新建 `experiments/F2_R1_<主题>_<日期>_vNNN/`，已存在目录拒绝写入。

### P1 数据与对齐（Agent 先行，Jade 抽查确认）

- 用 Praat 提取本人 10 段与 3 首原唱人声的 F0；复用 `f2/poc_phase4_realign.py` 的子序列 DTW + 调差搜索定位原唱候选区间。
- 输出逐段候选表：歌、版本、原唱区间、整体调差、置信线索。
- Jade 侧：用本地 `Qwen3-ForcedAligner-0.6B` 生成逐字时间戳并抽查（需要核对过的歌词）。
- 完成标准：每段本人录音都有 Jade 确认的原唱对应区间；对不上的标"待确认"，不硬配。

### P2 片段标注（Jade 主导，Agent 备料）

- Agent 按音符/长音切出候选偏差片段，整理成核对页（一轮一首歌、总时长 ≤10 分钟）。
- Jade 对每处标：**希望修 / 故意这样唱 / 拿不准 / 不需要修**，可补充说明。
- 完成标准：片段清单落盘，每条含时间、字、偏差（音分）、Jade 标记。
- 唱准和故意唱法的片段**保留**——它们是"不许乱改"的教学例子。

### P3 训练样本表（Agent）

- 从标注结果构建音符级样本表。特征：本人音高、原唱参考音、偏差音分、时长、前后音、句内位置、档位、歌；标签：目标修正量 / 不修。
- 目标修正量：扣除整体调差后向原唱参考音收敛；Jade 标"故意"的片段标签=不修。
- 划分：按歌分组，同歌不同版本不跨组。建议 心墙 + 离开我的依赖 = 训练，莫问归期（01、02）= 独立测试。
- 完成标准：样本表落盘并附统计（样本数、偏差分布、修/不修比例）。数字如实记录，不预设"够用"。

### P4 训练小模型（Agent，CPU）

- 先选型记录再动手，从轻到重：a) 统计基线（如"音程 → 系统性偏差"的中位数规则）；b) 表格模型（sklearn 梯度提升 / 岭回归，预测每音修正量或"是否真跑调"）；c) 更重的不在本轮。
- 选型记录：方案、项目地址、版本、许可证、接口、CPU 训练耗时。新依赖按规则新建环境。
- 完成标准：模型文件与训练记录（输入、参数、版本、环境）落盘；如实报告训练集拟合情况；有独立测试集的预测输出。

## 6. 术语小抄（大白话）

- **音分**：衡量唱偏多少的单位，100 音分 = 半个音阶台阶。人耳对长音上 150~250 音分的偏差才容易听出来，短音很难听出，所以本轮重点盯**长音**。
- **对齐**：找出"你唱的字"和"原唱的同一个字"各在几秒，程序才知道拿哪个参考音来比。
- **训练样本**：一条 = 一个音的"体检表"（你唱成什么、原唱唱什么、偏多少、多长），模型从一堆表里找规律。
- **权重**：模型学完留下的"经验本"。
- **拼接合成**：只把要修的音重新生成再接回去，其余原样保留——避免整段重合成带来的电音。
