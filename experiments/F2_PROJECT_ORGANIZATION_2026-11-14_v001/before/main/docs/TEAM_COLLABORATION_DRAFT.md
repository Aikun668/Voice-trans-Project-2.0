# 新阶段双人协作草案

状态：**讨论稿**。由 Jade 带给同学一起调整，负责人、时间和技术路线尚未由双方确认。

项目要做本人歌声美化和修音。F1 先围绕本人试唱数据探索小规模训练或微调，听结果后再改数据或模型。F2 要让音高更准，同时保留滑音、颤音、拖音和自然唱法。F1 与 F2 可以分开验证，再按实际结果决定如何组合。

## 建议怎么分工

| 人 | 建议承担 | 实际交付 |
|---|---|---|
| Jade | 负责整体目标、本人录音和授权、F1 听感判断与反馈。参与素材整理和模型实验方案，给同学说明什么效果有用、哪些唱法是刻意的。 | 录音及素材说明、试听反馈、问题优先级和阶段决策。 |
| F2 同学 | 主导音高问题的调查、数据判断和一个可重复验证的小实验。自己决定如何排查与解决，并说明证据。共同参与 F1/F2 接口和组合验证的讨论。 | 一份问题说明、可复现的实验、原声与结果对照、结论和下一步建议。 |
| 双方 | 共同选测试材料，讨论结果和模型路线，约定工作交接。遇到学术或算力问题时向老师汇报。 | 一份共享实验记录、待确认问题和双方认可的下一步。 |

这份划分承接原先 Jade 做 F1、同学做 F2 的分工。小模型路线是否也由同学参与训练、是否调整主责，应当听他的兴趣、已有基础和可用时间。

## 给 F2 同学的第一个真实问题

**怎样区分需要修正的跑调和歌手有意做出的滑音、拖音、颤音？** 之前部分“严重跑调”其实是有意夸张唱法，硬修正又出现电感。[路线图](ROADMAP.md)中 §2.2 的反馈和 §3.2 的 F2 事实可作为起点。

建议从一小段实际录音开始，让 Jade 标出“故意这样唱”和“希望修正”的位置。同学检查该段的音高轨迹与已有处理结果，提出一个可验证的判断或改进方法，保留原音及对照结果，最后请 Jade 听。任务的完成标准是能够说明哪一段、判断依据、实验方法与试听结果。即使结论是现有方法无法可靠区分，也应记录证据和下一步问题。

学习跟着这个问题走，建议顺序可以由同学调整：

1. **音频与音高基础**。采样率、波形、基频和音高轨迹分别表示什么，用现有音频查看一段轨迹。入口是 [F2 Phase 1 记录](../f2/PHASE1_NOTES.md)。
2. **分析已有处理流程**。理解 F0 提取、目标音高、波形重合成各自做什么，指出错误目标音或重合成可能如何影响结果。入口是 [F2 Phase 2 记录](../f2/PHASE2_NOTES.md)和 [ROADMAP](ROADMAP.md) 的 §3.2。
3. **做一次有对照的实验**。固定输入、记录参数与运行环境，保存音频、测量和人的评价，说明哪些证据支持结论、哪些问题仍未解决。
4. **再了解机器学习与部署**。围绕训练集与独立测试集、过拟合、预训练与微调、推理性能提出问题，结合后续 F1 小模型试验学习。模型选型和训练方式由双方后续讨论。

这些工作能练到读代码、信号分析、实验设计、定位问题、写结果和解释技术取舍。由同学负责提出方案并汇报，Jade 提供目标与实际反馈，两人一起复盘。

## 交接和记录

- 每项任务写明问题、输入、谁负责、预期交付和何时碰头。时间按双方实际安排。
- 一次实验保留输入来源、代码版本、参数、输出、工程检查、本人听感和失败记录。原始录音只读。
- F1 输出与 F2 输出各可独立对照。接口先沿用 WAV 和保留演唱时序的方向，采样率、声道、精确容差及组合顺序待双方实测协商，旧接口文档见[归档](../archive/PoC_2026-10/PoC%20F1%20%20F2%20接口对齐契约%20v1.0.md)。
- 两人讨论结论后再把确定的分工和方向更新到 [ROADMAP](ROADMAP.md)。每轮反馈继续记录原话。
