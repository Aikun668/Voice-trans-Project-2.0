# SHIGE：保留原相位的神经美化适配

目标：交付可试听的完整SHIGE美化WAV，改善音色且保留本人、字头/清音、真实音高和节奏。主交付只能为原音与完整美化候选，声码器/重建只作内部证据。工程通过后听感仍pending_jade。

已确认：原a2a重建也有局部严重衰减；a2p在其上增加颜色变化。均值修订未解决。Jade反馈新声码器SHIGE仍跳变，既有全局采样差指标漏检。不能再次以这些指标通过为“无跳变”的听感结论。

诊断补充：原Praat AC 0.6在SHIGE约16.65s有一次相邻有声帧超过600音分的跃变；相同录音的librosa0.9.2 pYIN没有该跃变。两者其他帧亦有分歧，不能直接认定pYIN是真值，暂不将pYIN整体替换用来追求通过指标。最终重建保留原相位，避免以估计F0重新合成声源。

## 本轮唯一机制假设

`mel_enhanced = mel_original + strength * (mel_a2p - mel_a2a)`，使用完全相同的源音高/内容/说话人条件和同一个后验潜变量。差异来自官方神经映射及解码，不用固定EQ冒充模型变化。

用原模型的mel滤波器权重，将该对数幅度差投影到对应线性频率网格；原44.1kHz波形用librosa STFT/ISTFT保留相位重建。模型未覆盖的高频原样保留。该方式是项目的神经频谱增益适配，不是NeuralSVB官方完整生成路径，也不是新训练的美化模型。

必要性：不把a2a重建损伤当美化效果，不让声码器重新生成原本正常的音高、辅音。没有手工补字、片段拼接、原音波形混合、音高纠正、节奏修改、动态补洞或阈值放宽。

候选最多两条：strength=0.5、1.0，只改映射差分强度。若均无可感知收益或仍有副作用，不宣称此适配成功，不继续无上限加参。先只跑SHIGE正常版。

## 生成前的测试与门槛

- 关闭映射（mapped==reconstruction）时输出必须还原输入；重建分支本身的衰减不能泄漏进候选。
- 保留原44.1kHz/mono/PCM16和全部样本数。未覆盖高频不得被重采样丢弃。
- 原相位STFT往返、信号长度与有限性测试；额外合成信号验证基频和高频保留。
- 每条候选跑原f1_poc.compare_audio完整门槛，包括本轮可适用的波形相关性、频带变化，另核验源/旧实验哈希、完整解码、削波、真峰值和响度匹配。
- 模型有效性：记录a2p-a2a差分强度、频段差异及关映射反事实，不能把单纯声码器变化或固定音量当作美化。
- 不以工程通过宣称“更好听、无跳变、无沙哑、未变嗲”；这些必须由Jade确认。
