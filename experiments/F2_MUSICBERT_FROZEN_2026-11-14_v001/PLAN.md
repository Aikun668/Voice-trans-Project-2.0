# MusicBERT 冻结权重适配执行计划

执行方式：本会话直接执行，使用 writing-plans / executing-plans / verification-before-completion。用户已明确“开始、其他你处理”，不另设审批轮。项目原有文件只读，实验目录承担隔离，避免新工作树丢失现有未跟踪素材。规范见 [rules.md](rules.md)。

## 1. 冻结资产和作用证明

- [ ] 保存主线及源素材指纹，下载官方 small 权重、编码词表、上游运行代码/许可证。
- [ ] 优先复用 MusicBERT 的维护者 HuggingFace 适配；完整检查原始掩码头加载，不增加未经训练的任务头。
- [ ] 核对冻结状态、确定性、非零上下文作用、词表/八元组编码。保存 no-training 证据。

## 2. 输入、推理和声音执行

- [ ] 写风险测试并见到预期失败：全静音/短音不修、零修正逐样本旁路、目录覆盖拒绝、无参考访问、词表越界拒绝、完整加载缺参数拒绝。
- [ ] adapter.py：复用原音高提取及 Praat 合成，只实现音符接口、八元组编码、原权重留一掩码建议及预先固定安全筛选。
- [ ] infer.py：只接收本人原音与 assets，保存原始建议、筛选理由、实际移调命令和输出。原唱/人工标签在该进程不可访问。

## 3. 固定筛选与是否微调判断

- [ ] evaluate.py：其他歌固定控制集测试，比较正常音保留、受控错音恢复、打乱前后文和简单规则，不用《心墙》挑阈值。
- [ ] offline_review.py：推理完成后核对本人已确认问题和全部改动；可信目标不足则明确待核。
- [ ] 保留所有失败及被筛除结果，按 rules.md 10–15 给出是否值得微调的条件性意见。

## 4. 交付和严格复核

- [ ] deliver.py：原音与处理版同响导出，单播放器切换、复制反馈，听感待 Jade。
- [ ] verify.py：独立重载/重算模型和输出证据；全部 WAV 解码、样本数、响度、真峰值、音高执行和原音哈希检查。
- [ ] 浏览器实际播放/切换/复制检查，写 REPORT.md 和规则证据表，核对主线指纹未变。

## 重点风险

1. 原 MusicBERT 为乐谱预训练；清唱音符估计与节拍映射可能偏离训练分布，失败不唯一归因模型。
2. 原掩码头输出必须来自预训练参数；不能把随机任务头、局部规则结果说成模型修音。
3. 模型在正常音上也可能更喜欢另一个合理音，严格记录误改和被过滤比例。
4. 自动专业版音符只作为受控练习的原序列，不是任意真人跑调的人工真值。
5. 用户不能被“工程通过”和几乎原样旁路误导；筛选失败必须在试听页显示。
