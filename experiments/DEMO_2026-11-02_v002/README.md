## 诊断证据

- WPE（nara_wpe 0.0.11, MIT, 安装于 F1_demo_chain_2026-11-02_v002/vendor，未改源码；click 用空装饰器替代）：常规参数各电平段去除 <1 dB；短延迟参数在响段去除 12–18 dB（吃掉歌声的周期成分），不可用。
- 长时平均谱（响段，总能量归一）：本人薄音版 vs 录音室人声：125–200 Hz +7~+10 dB，2–3 kHz −18 dB；V1 未改善中高频缺口。
- 匹配后与录音室音色差（100–6300 Hz，1/3 倍频程 RMS）：原 9.4–11.5 dB → V3 4.1–5.9 dB。
- V3 句间底噪（P5−P95）：-38→-50、-38→-49、-33→-45 dB；雅俗共赏 -28→-25 dB（底噪贯穿演唱，句间下压作用有限）。齿音指标与原音持平；动态 P95−P30 从 8–11 dB 压到 2.3–4.2 dB（与 V1 相近）。
- 音高：V3 相对原音中位偏差 ≤0.4 音分。首版 V3 在 125–200 Hz 削 3–5 dB，Praat 浊音帧丢失到 0.895（我们的歌 F0≈136 Hz），确认为削到基频，已改为 250 Hz 以下只升不削，恢复至 0.92–0.96。
- F2 phase4b：各修正段实际移调与目标差中位 0.2–0.8 音分，最大 4.6；修正段外与原音一致（差异仅在 20 ms 交叉淡化内）。重合成占比 7%/18%/24%。
- 对齐：自由飞翔 severe/medium/normal 与凤凰传奇原唱人声对齐代价 70/54/43（反转基线 95/97/84）；最炫 severe/mild/normal 77/83/73（反转基线 101/102/103），对齐可用但弱于刚好遇见你（34 vs 108）。
