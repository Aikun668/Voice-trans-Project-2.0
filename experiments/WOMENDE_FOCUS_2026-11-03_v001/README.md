# 我们的歌·薄音版 定点：发声力度（2026-11-03 v001）

Jade 要求只看一首，弄清"声带发声力度"差在哪、能不能模拟（不只是变响）。试听页 `index.html`，全部 -18.5 LUFS 等响。听感：pending_jade。

## 步骤

1. `align_ref.py`（.venv-f2）：薄音版、正常版分别对齐王力宏人声轨（phase4 子序列 DTW）。薄音版 → 15.5–29.1 s，调差 −350 音分；正常版 → 107.8–121.7 s，调差 −40 音分。薄音版对正常版：同旋律，整体低 310 音分（IQR −328~−288）。
2. `measure_source.py`（.venv-f2）：只统计响段浊音帧 → `source_measures.json`。

| | 薄音版 | 正常版 | 王力宏(薄音对应段) | 王力宏(正常对应段) |
|---|---|---|---|---|
| F0 中位 Hz | 136.2 | 158.4 | 159.8 | 160.2 |
| H1−H2 dB | 4.60 | 2.45 | 6.78 | 6.54 |
| H1−A3 dB | 37.09 | 24.43 | 27.38 | 26.37 |
| alpha ratio dB | −27.43 | −16.05 | −17.67 | −16.84 |
| HNR dB | 19.67 | 16.54 | 14.99 | 12.93 |
| CPPS dB | 7.15 | 9.24 | 8.57 | 7.03 |

结论：差距在 ① 调低约 3 个半音、② 高次谐波（alpha ratio / H1−A3）少 11–13 dB；气声（H1−H2）不是问题。正常版在这些指标上已接近王力宏。

3. `prep_pitch.py`（.venv-f2）：整体 +310 音分（f2/poc_phase1.shift_uniform，Praat PSOLA）。
4. `harmonic_tilt.py`（.venv-f1-adaptive）：浊音帧、谐波峰附近（高斯 σ=0.12·F0）施加 700 Hz 起每倍频程 S dB 的增益，5–10 kHz 收回，单点上限 15 dB；二分求 S 使 alpha ratio 达正常版。清音、谐波间隙不动。

## 结果（report.json）

- C1：S 达上限（7.99 dB/oct，5 kHz 处 15 dB），alpha −27.4 → −20.0（目标 −16.1，补了约 65%）。
- C2：升调后 alpha −28.0 → −20.1，同样触顶。
- 音高：C1 相对原音中位 +0.1 音分；C2 相对只升调版 +0.1；只升调版 +310.4。浊音帧重合 ≥0.985。
- 齿音段指标（5–9 kHz 相对全带 p99）三者均 −2.2 dB，未变。
- 样本数一致，真峰值 ≤ −1.4 dBTP。

## 风险 / 未验证

- 薄音版 3–5 kHz 的谐波可能本身被噪声淹没，抬 15 dB 可能抬出毛刺；上限是保守选择，未尝试更高。
- 升调属于修改音高（超出 F1 约定），这里只作为"差距来源"的诊断候选；之前 F2 反馈过抬音高会"发软/嗲"。
- 王力宏轨为 Demucs 分离，含混响与制作处理，只作方向参考。
