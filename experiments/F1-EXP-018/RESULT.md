# F1-EXP-018 结果（pending_jade）

F1-P4b 无配对参考迁移·第二样本。第一样本 A05（GTSinger 女声 女A-002，F0≈290Hz）用户反馈"三个版本听不出区别"，本轮换用 M01（GTSinger 男声 男A-001，F0≈222Hz）。

模板、机制、门槛与 F1-EXP-017 完全一致（同一套 4 对 Dev 固定中位模板，重新计算以验证可复现性），未改参数、未读目标参考、未新增模块。

## 换样本的技术理由

女声样本 F0≈290Hz → 第 2 泛音 580Hz，使 250–500Hz"厚度区"内只有基频一根，模板在该区只能作用到 H1（+1.4dB），无法增密——正好踩在方法的覆盖盲区上。
男声样本 F0≈222Hz → 第 2 泛音 444Hz 落在厚度区内，模板可对该区直接作用。这是"方法覆盖范围内"的检验。

## 客观结果

| 指标 | 原音 | X1 | X1+M2 |
|---|---|---|---|
| H1−H2 | 17.01 dB | **15.07** | **15.04** |
| 谐波丰富度(2–23) | −27.88 dB | **−26.10** | **−25.96** |
| 频谱重心 | 276 Hz | **312 Hz** | **370 Hz** |
| 音高中值 | 222.6 Hz | 222.3 Hz | 222.3 Hz |
| 时间对齐 | — | 0 样本 | 0 样本 |
| 削波 | 0 | 0 | 0 |
| 匹配后响度 | — | −18.01 LUFS | −18.00 LUFS |
| 真峰值 | — | −6.32 dBTP | −6.03 dBTP |

- 改善量：H1−H2 **1.94dB**、丰富度 **+1.78dB**、重心 **+36Hz**（M2 再 +58Hz）。
- 对比第一样本（女声）：1.19dB / 1.03dB / +60Hz —— **男声样本的谐波改善量约为女声的 1.6 倍**，与"H2 落入厚度区"的技术预期一致。
- 对比逐例定制（EXP-015 在 A01 上改善 5.5dB）：固定模板仍只有其约 1/3。原因：4 对缺口量级差异大，中位模板必然摊薄。

## 关键发现（本轮最有价值的信息）

在**无配对参考、固定模板、约 2dB 量级**的条件下：

- **可被耳朵抓住的是"包络/宽带频谱形状"（M2）**：它把重心从 312Hz 推到 370Hz（+58Hz），这一项被听出来；
- **不是"谐波精细结构"（X1）**：它把 H1−H2 改善了 1.94dB、丰富度 +1.78dB，却完全听不出。

这与 EXP-016 的模式完全一致（那里也是 X1+M2 成为最佳、X1 单独不突出）。也解释了此前反复出现的体感：**能被感知的始终是"更亮/更清晰"的宽带变化，而不是"更厚"的谐波结构性变化。**

## P4 路线的结论（两个样本对照）

| 样本 | 音高 | 覆盖情况 | 结果 |
|---|---|---|---|
| A05 女声 | 290Hz | 厚度区仅 H1（盲区） | 三版均无可听差异 |
| **M01 男声** | **222Hz** | H2=444Hz 落入厚度区 | X1 无差异；X1+M2 有点点效果 |
| A01 自录（配对参考） | 176Hz | 全覆盖 | X1+M2 达"更饱满/更清晰，需认真听"（EXP-016 最佳） |

**结论：无配对参考时，本方法的能力上限约在"有点点效果"；配对参考路线的改善量约为其 3 倍，且是已被认可的最佳版本。**

## 局限

模板来自 4 对同年自录（137–226Hz）；M01 音区与该域接近，属方法覆盖较好的情形，结论不可外推到女声/高音区；M01 无配对正常版，只能判断"有没有改善"、不能判断"差多少"；自实现机制未与外部工具校验；Agent 未听音。

## 下一步选项（待用户决策）

1. **停止 P4 路线**，回到配对参考路线并明确其使用条件——需同一歌手先唱一遍"正常版"作为参照，是目前唯一达到"更饱满/更清晰"的路径；
2. **按音区分档模板**：用 Dev 数据按音区切片替代单一中位模板。本质是同一机制的参数细化，预期收益有限（可能把"有点点"推到"勉强可辨"，难达"明显"）；
3. **强化 M2 包络档位**：加大宽带整形量。但历史证据（EXP-010/011）表明该方向只会走向"更亮/更清晰"，不等于"厚"，且会放大齿音/嘶声；
4. **越界试验**：F0 活跃度注入或咬字位置上移，需用户明示授权（违反 F1 不改音高/咬字约定）。
