# F1 实验日志（Phase-2 起）

本日志记录 F1 单薄人声美化的近期实验、参数、结果与路线决策。旧路线见 `docs/F1_REBASE_2026-10-27.md` 及各历史实验目录；本文件从 Phase-2 开始追加，不覆盖旧记录。

## F1-EXP-001：单模块 EQ（Phase-2）

- 目的：验证 E1 低架主体 / E2 高架存在感是否能改善单薄感。
- Dev：A01/A02/A03/A05/B01/B02；Holdout A04/A06/B03/C03 未处理。
- E1：LowShelf 220 Hz，+2.0 dB，Q 0.7。
- E2：HighShelf 3000 Hz，+1.5 dB，Q 0.7。
- 结果：E1 6/6 无可听改善；E2 仅 A01 极轻微，普通听无差异，起始 1–2 秒有轻微“饱和/发紧”感；其余无差异。
- 技术：无削波、无异常增益、长度/格式不变；试听版等响。
- 状态：暂停；代码/音频保留。

## F1-EXP-002：EQ 有效性诊断（Phase-2.1）

- 目的：判断差异不明显是强度不足、处理链问题，还是方向无效。
- 样本：A01/A02/A05/B01；Holdout 未处理。
- 参数：E2-1.5 与 E2-4.0（HighShelf 3000 Hz，Q 0.7）。
- 技术：频响符合设定；线性误差 <1e-6；无削波；等响后 EQ 倾斜保留；A/B 映射/播放正确。
- A01 起始异常：未找到滤波瞬态、非线性、削波或边界原因；前 2 秒高频占比不高于后段；上轮 +1.5 的轻微变化未复现。
- 听感：7/8 处理对比无可听差异；A02 +1.5 极轻微且需刻意听；A02 +4、A05/B01 +1.5/+4 均无差异。
- 状态：negative_no_stable_effect；不进入下一阶段。

## F1-EXP-003：EQ 最后一档强度（Phase-2.2）

- 目的：用户要求最后测试更强的高架强度，确认是否只是强度不足。
- 样本：A01/A02/A05/B01；Holdout 未处理。
- 参数：E2-4.0 与 E2-8.0（HighShelf 3000 Hz，Q 0.7）。
- 技术：+8 频响到位；线性、无削波、等响后倾斜保留；A/B 映射正确。
- 听感：A01 +8 比 +4 更强，两版都比原音更亮、略饱满，但部分像音量增大；A02 +8 更亮/清晰，+4 无差异，低沉感仍在；A05/B01 反而 +4 更清晰，+8 不明显。
- 结论：+8 可以制造“更亮/更清晰”，但不能稳定制造“更饱满”；低频/低沉感仍在；强度顺序非单调、样本依赖。停止单独优化 EQ 参数族；+8 作为“亮度/清晰度”候选保留，未来仅在独立对照的复合实验中考虑，不作为当前饱满度主线。

## 路线决策：为什么转向谐波饱和（F1-P3A）

- 旧 EQ 路线撞到的墙：1) 亮度/清晰度可被改变，但饱满度无稳定提升；2) 高频强调容易被感知为“更响”，等响匹配也无法消除这种响度感；3) A05/B01 出现强度顺序非单调，样本依赖明显；4) +8 dB 已到可听上限，继续加量不合适；5) 处理链技术验证通过，因此不是链故障。
- 已验证的结论：EQ 可以带来可听的亮度/清晰度变化；不能解决低沉、偏薄的主体感；+8 不宜作为默认参数。
- 转向理由：谐波饱和通过非线性谐波/软压缩改变音色密度，机制不同于高架 EQ；本轮只验证 Soft Saturation 单模块，不叠加 EQ/压缩。
- 保留：EQ 代码、参数、输出与 +8 结果全部保留；未来只允许“独立对照”的 EQ + 饱和组合，不默认叠加。
- 并行压缩：仅作为另一条候选记录，本轮不实现。

## F1-EXP-005：P3A-2 增强谐波饱和（待试听）

- 原因：F1-EXP-004 的 Light/Medium/Strong（drive 1.5/3/6，wet 0.5）用户听不出 A/B/C 与原音差异，判断首档饱和过轻。
- 参数：同一 soft tanh；4x oversampling + 20 kHz 低通；Wet/Dry=0.7；Light/Medium/Strong drive=3.0/6.0/12.0。
- 样本：A01/A05；Holdout 未处理；无 EQ/压缩/模型。
- 技术：无削波、长度不变、时间对齐 lag=0；试听版等响约 -18.55 LUFS；A/B/C 随机隐藏。
- 状态：negative_audible_but_muffled；结果见 `experiments/F1-EXP-005/`。
- 用户听感：A01 A（Medium/6）略变化，B（Light/3）中等偏闷，C（Strong/12）更闷；A05 A（Light/3）无区别，B（Strong/12）/C（Medium/6）有不同程度闷感。
- 结论：提高 wet/drive 后变化可听，但主要变闷，不是饱满；暂不继续加 drive/wet。
## F1-EXP-006：P3A-3 固定 drive 的 Wet 诊断（待试听）

- 目的：固定 soft tanh drive=3，仅比较 wet=0.5/0.6/0.7，判断是否存在可听但不闷的中间区间。
- 复用：wet=0.5 来自 F1-EXP-004 Medium；wet=0.7 来自 F1-EXP-005 Light；wet=0.6 本轮生成。
- 样本：A01/A05；Holdout 未处理；无 EQ/压缩/模型。
- 技术：无削波、长度不变、时间对齐 lag=0、等响约 -18.55 LUFS；复用文件 hash 一致。
- 状态：terminated_no_valid_interval；结果见 `experiments/F1-EXP-006/`。

- 结论：未找到可听、不闷、饱满有改善的有效区间；停止当前 tanh 实现并归档，不继续扫描 Wet 参数；不否定谐波增强方向。
