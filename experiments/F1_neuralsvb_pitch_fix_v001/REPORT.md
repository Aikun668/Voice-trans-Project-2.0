# F1 NeuralSVB 路线 1：音高输入核查（SHIGE）

- 范围：只在 contract_v001 完整链上，把 SHIGE 16.654–16.684 s 共 6 帧 F0 由约 116 Hz 改为 pYIN 的 233–234 Hz。其余帧、模型、种子不变。
- 工程：base 复现 contract_v001（最大样本差 ~1e-5）；vocoder 通过，a2a/a2p 仍因局部音量骤降被拦（改前改后一致）。
- Jade 听感（原话见 shige_control/feedback.json）：16.5–17.4 s 无异常、听不出区别；沙哑/变嗲/仅声码器均“没有变化”。
  → 16.65 s 的锚点不对应可听问题；路线 1 对 SHIGE 记“已排除”（不是主因）。听感状态仍为 Jade 反馈，不替她填通过。
- 新线索（Jade）：0:03.2 “是谁在唱歌”后有“呱”声；整体像“鼻子发音”，改前改后一样。
- 只读测量（不是听感）：原音 2.95–3.65 s 为很轻的非歌唱段（-31~-46 dB），Praat 与 pYIN 均判无声，不是音高读错。
  该段 1.5–4 kHz 能量：原音≈8–12 dB；仅声码器≈10–13 dB（基本跟原音）；a2a≈20–30 dB、a2p≈13–27 dB（高出 10–20 dB）。
  → “呱”与模型输出相关，声码器基本忠实；指向路线 3（声学模型/映射），待路线 2 先确认声码器。
- 未验证：上述测量与“呱”“鼻音”听感的因果；鼻音是否来自模型的 0.5–4 kHz 能量抬升。
