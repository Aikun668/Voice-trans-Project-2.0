# NeuralSVB 当前试听收益退化调查

日期：2026-10-26。范围：读取既有代码、报告、中间特征和 WAV，核验当前 HTTP 音频，运行描述性测量。没有修改生产代码、旧实验或音频，没有加载模型重新推理，没有生成候选。Agent 无直接听音能力，听感以 Jade 反馈为依据。

## 结论

当前页面不是旧完整 NeuralSVB 输出的单纯接口修正版，而是另一种实验处理方式：原音频谱乘以从 a2p/a2a 差分构造的时变增益，再用原相位合成。旧的完整生成结果不再作为输出，声码器也被旁路。不能以当前听感直接得出“修正接口破坏了 NeuralSVB 美化”。

当前方案有实际处理，非文件相同/页面给错音频；但它去掉了完整生成过程的许多变化，交付的频谱形状变化显著小于旧版。将“美化与重建之差”当作“可移植到原音的完整美化收益”未经验证。当前失败主要应按该新适配机制收益不足处理，而非继续把它称作原美化算法修复后没效果。

## Jade 本轮反馈

- 当前试听非常差，感觉完全没效果。
- 修正前虽有跳变、沙哑等明显副作用，但能听到不错的美化收益；这些收益不能在修复过程中丢掉。
- 这是对当前 A/B 的否定反馈，不是所有 NeuralSVB 输出都没有收益的结论。旧版是“有收益且有副作用”的参考，不是已获最终验收的版本。
- 当前实验听感记为 feedback_received_not_accepted / no_clear_benefit，整体不通过听感验收；不覆盖旧实验的 pending/失败历史。

## 实际版本链路

| 实验 | 实际输出方法 | 已核对事实 |
|---|---|---|
| F1_neuralsvb_v002 | PWG 50–11025 Hz/log10 → 旧固定补帧 F0 → 完整模型 → 原声码器 | Jade 听到收益，也有沙哑/变嗲/跳变；原始文件保持 |
| F1_neuralsvb_vocoder_range_v001 | 只过声码器，对照 50–11025 与 0–8000 Hz，固定原 F0 | 匹配范围未改善，音高诊断更差；没有建立“0–8000 是正确训练输入”的结论 |
| F1_neuralsvb_contract_v001/full_normal | 保留 PWG 50–11025，修正 Praat 帧中心，完整模型 → 原声码器 | SHIGE 完整输出仍有局部衰减，技术拦截；不能据此认为所有音色变化都无益 |
| F1_shige_neural_residual_v001 | a2p-a2a → 频率网格加权平均 → 原音幅度增益 → 原相位合成；0.5/0.75 | 当前 52876 页面；不使用声码器输出，是新的实验机制 |

contract 实验还改变了尾帧处理、随机性管理和外部格式转换。因此旧文件与该实验不是所有其他变量严格相同的单变量对照。当前证据可以拆清版本和测量差异，不把全部差异单独归给 F0。

## 文件核验

- HTTP index.html 指向 residual 实验的 delivery/ 三条文件。
- 三条 HTTP 文件 SHA256、磁盘 SHA256 均与 delivery_manifest.json 一致。
- 原素材及 v002 四条 SHIGE 处理文件 SHA256 与旧 report.json 一致。
- 当前 A/B 与原音不同：相同采样值比例仅约 0.55%/0.44%；与原音波形相关性分别 0.98966/0.97642。相关性不是悦耳度指标，也不证明人耳应该感知收益。
- 本次未自动操作浏览器按钮；核验的是页面声明的目标与实际 HTTP 字节，不能声称复现了用户设备播放状态。

## 为什么新机制可能拿掉了原收益

原模型给出两个完整特征结果：a2a（同一声音的模型重建）和 a2p（映射后的目标音色）。原音特征记 x，a2a 记 a，a2p 记 p。

- 原完整目标相对原音的变化是 p-x。
- 新适配只保留 p-a，并缩放为 0.5 或 0.75，再在原音上施加。
- 即使强度为 1，理想特征表达也只是 x+(p-a)，与 p 相差 x-a，除非 a 正好等于 x。

实际 a 并不等于 x。源 mel 能量加权的变化 RMS：a-x 为 6.50 dB，p-x 为 10.98 dB，p-a 为 5.85 dB。这里是描述性特征尺度，不是听感分数，也不能把比例当成“保留了多少美化”。

把 a2a 的变化全部去掉，会同时去掉重建损伤、模型的其他音色变化；没有证据证明被去掉的全是坏处。两条模型分支差值非零，只证明使用了模型差异，不证明它保留了 Jade 喜欢的部分。它们还共用非线性解码器，原模型没有训练这个差值作为原录音的可直接移植增益。

此外，新适配用归一化 mel 基底转置对 log 增益加权平均。这是自定义增益投影，不是严格的 mel 逆变换，也没有验证投影回原音后等于目标模型频谱。原相位与原录音声源被保留；声码器带来的重新合成变化被整体取消。不能认定取消的内容只有沙哑、跳变。

这超出采样率、格式和电平这样的边界适配：它是另一种模型驱动频谱增益方案。用到官方模型是真实的，但不能据此称其保留了官方完整生成的等效美化能力。

## 为什么报告中“7 dB 变化”不能证明效果明显

模型 p-a 在所有 mel 位置等权计算的 RMS 为 7.03 dB；当前适配报告的投影增益 RMS 为 A 3.07、B 4.60 dB。这些统计也包括低能量频带和时段，且包含整体增益分量。

以原录音 STFT 能量加权分析，完整强度投影的平均 log 增益为 -5.07 dB；去除全局常数后，形状变化 RMS 为 2.47 dB。按 A/B 强度缩放约为 1.24/1.86 dB，之后还经历相位合成和响度匹配。这不是实测 LUFS 增益，不能直接用于推算人耳差异；但说明“原始增益 RMS 很大”容易夸大剩余音色变化。

实际最终 WAV 用相同提取规则分析，剔除恒定整体增益后的源能量加权 log-mel 形状距离如下：

| SHIGE 版本 | 描述性距离 dB |
|---|---:|
| 旧 v002 完整 a2p | 5.25 |
| 修正时间轴后的完整 a2p | 4.75 |
| 修正时间轴后的 a2a | 4.58 |
| 修正时间轴后的纯声码器 | 1.86 |
| 当前差分方案 B | 1.73 |

测量方法：既有 WAV 读入；44.1 kHz 用 SciPy 转为 22.05 kHz；统一 FFT/window 512、hop 128、80 mel、50–11025 Hz、log10 幅度；按共同原音时间范围与原 mel 幅度平方加权；减去每个版本相对原音的加权平均增益。它不能区分好听变化与损伤，也未做听觉对齐/感知评分；只说明当前输出相比旧生成输出显著更接近原频谱。

当前 B 的旧频带诊断为低频相对 -1.42 dB、中频 +1.18 dB、高频 +1.37 dB；因此当前更像有限的时变音色平衡，不能因波形技术保真而推定原本想要的神经美化已交付。

## 接口诊断中应纠正的认识

前一轮确认了两份配置的频带定义不同，却没有确认公开声码器权重真实训练时的全套提取约定。因而“配置不同”成立，“必然造成这些沙哑/跳变”未证实，“按0–8000改就会修复”不成立。后续单项实验也不支持该修法。应修正此前过强的因果表述。

时间轴修正确有工程证据：contract 报告中 SHIGE 纯声码器音高诊断约由旧 12.4/78.4 降至 3.21/18.61 音分，但这不能证明音色或美化收益变好，亦不是所有变量严格相同的配对因果试验。

完整声学模型的局部衰减还存在：SHIGE a2a 约最低 -20.98 dB、a2p -26.44 dB，多在 0.8–1.0 与 16.8–17.0 s。它们需要定位，不能因局部问题而把全程模型变化统统当成损伤抛弃。无基频不等于没有清音或歌词。

## 对验收和下一步的建议（未实施）

1. 暂停当前 residual 适配作为交付方向，不继续以加大 strength 追收益。1.0 已有局部工程报警；当前用户反馈也没有建立正向听感基线。
2. 保留旧 v002 作为“有美化收益但有副作用”的研究参考。不能将旧基线直接改判合格，也不能在新方法中默认它的益处已经保留。
3. 用现成的旧完整输出、时间修正后完整输出和内部 a2a 诊断，定位 Jade 喜欢的变化是否仍在完整生成分支，区分声码器、重建与映射贡献；不再把纯声码器或差分波形替代完整美化。技术拦截文件仅作为内部诊断，不当成已可交付候选。
4. 若继续修复，选择同一条已有收益素材、保留完整生成机制，每次只改一个已定位的原因，并同时检查副作用是否减轻、原有收益是否保留。没有听感确认前不自动把模型重建变化当纯误差。
5. 若完整生成对当前中文本人素材的音素/音色保真无法以低成本解决，明确记录该候选限制，再讨论替换兼容模块。不要为通过检查静默改造成另一类处理方案。

工程门槛应继续拦截损伤；需要补齐的是收益保留验收，不是调宽阈值。当前测试验证了开关映射、增益运算、时长和高频保留，没有验证“旧版正向美化收益被保留”。技术通过与用户验收的差距就在此处。
