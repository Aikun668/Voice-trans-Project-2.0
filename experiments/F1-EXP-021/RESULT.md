# F1-EXP-021 结果（pending_jade）

F1-P7 起音瞬态增强：基线 = EXP-020 S45（X1+M2+F1 最大档，原样引用）。只对"可靠元音起音"施加短时增益，持续段完全不动。

## 起音检测可靠性

| 项 | 值 |
|---|---|
| 分析帧 | 2624 帧（25ms 窗 / 5ms 步） |
| 浊音占比 | 75.2% |
| **检出元音起音** | **27 个（2.05 个/秒）** |
| 起音间隔中位 / P10 | 372ms / 90ms |
| 因"无能量跃升"被拒 | 1921 帧（持续段，符合预期） |
| 因"后续未保持浊音"被拒 | 23 帧（爆破/咔哒，已排除） |

三重判据：浊音（r≥0.45，排除清辅音与噪声）+ 相对前 15ms 跃升 ≥6dB（或前一帧为清音）+ 其后 20ms 保持浊音。**检测可靠，辅音与爆破未被误标。**

## 处理结果

| 项 | T15（轻） | T30（中） |
|---|---|---|
| 施加包络峰值 | **1.50 dB** | **3.00 dB** |
| 峰值窗口实测 | +1.15 | +2.32 |
| 全窗口中位实测 | +0.92 | +1.88 |

| crest 因子 | 16.83 | 17.37（基线≈16.4） |

**关键：持续元音主体的增益实测为 0.00dB，确认"只改起音、不动主体"的约束被严格执行。**

施加包络峰值精确 1.5/3.0dB；25ms 窗口实测偏低 0.35/0.68dB，原因是窗口比 50ms 包络短，必然把两端衰减段平均进来——属测量口径效应，非处理不足（P90 已达 2.71dB，接近 3.0）。

响度目标降至 −20.48 LUFS（非 −18），因为 T30 起音峰值抬高后真峰值达 −2.96dBTP，无法在 −18 LUFS 下保持 3.2dB 余量。四个文件统一，无限制器。

## 验收

两档均 technical_pass：音高不变、时长/样本数不变、无削波、持续段零泄漏、响度一致。

## 用户听感

> "感觉后面机械和AB没什么区别啊"

**两档起音增强（+1.5dB / +3dB）与基线无可听差异 → 按预定停止条件，起音方向终止，不加量。**

新增阈值数据点：本比起音增益作用于 50ms 窗口、累计仅 1.35s/13.14s（10% 时长），3dB 的局部峰值抬升完全不可闻。与之前"3–5dB 全段谐波改善才勉强可辨"一致，进一步确认：**感知门槛是全局量级，局部小比例改动不产生可听收益。**

## 局限

起音检测依赖自相关周期性，气声极重的起音可能被漏检；20ms 窗口在极快咬字处可能跨越音节（已用最小间隔 12ms 与 max 叠加规则限制）；自实现机制未与外部工具校验；Agent 未听音。
