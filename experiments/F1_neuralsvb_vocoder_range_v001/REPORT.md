# 第一项实验结果：只匹配声码器的频谱范围

结论：已完成这项实验。最终文件满足 44.1 kHz / 单声道 / 16-bit PCM 接口，范围匹配版本仍未通过音高工程拦截。当前证据不支持把“只改为 0–8000 Hz”作为修复，也不支持认定沙哑/跳变已经消失。Agent 无直接听音能力，未作听感判断。

## 接口与处理范围

- 外部输入/最终输出：44100 Hz、单声道、16-bit PCM WAV，完整 1039526 样本 / 23.572018 s，与原音时长和样本数一致。
- 模型内部：22050 Hz；用既有 SciPy resample_poly 转换回 44100 Hz 后统一导出。上采样不增加真实带宽，所以格式契约成立不代表保留了 44.1 kHz 原录音的全部高频细节。
- 声码器：官方 HiFi-GAN-Singing NSF 1012 / step 1170000；未调用声学模型、PPG 或音色编码器。
- 基线范围 50–11025 Hz；实验范围 0–8000 Hz。均为同一官方 PWG 提取代码、log10 幅度谱、FFT/window 512、hop 128、相同帧中心/补边。
- 两次生成前都固定种子 0；共用一次提取的完全相同 F0，未修正其时间轴。改变的是 fmin/fmax 这一组频率范围参数。
- 保留全部特征帧；两条生成后都只去掉超出原始时长的 90 个重采样尾部样本，没有补零、拉伸或截短原始有效时长。
- 此基线为重建的新基线，不与 v002 位级复现：本轮明确固定了声码器随机性，并避免旧声学模型所需的四帧裁剪。两条本轮对照采用完全相同规则。

## 音高与动态诊断

本表来自最终导出的实际 PCM 音频；既有检查函数的第二音高工具固定接收 22050 Hz，因此先将最终 44100 PCM 重采样为原生速率分析。最终文件的外部接口、响度、真峰值和样本数另行直接核验。

| 项目 | 当前范围基线 | 0–8000 Hz 范围匹配 | 原有拦截线 |
|---|---:|---:|---:|
| 项目音高估计：中位绝对偏差，音分 | 17.23 | 32.04 | ≤10 |
| 项目音高估计：P95 绝对偏差，音分 | 106.76 | 1201.48 | ≤35 |
| 项目音高估计：可比较帧 | 855 | 507 | 仅作覆盖情况记录 |
| Praat：中位 / P95 绝对偏差，音分 | 18.05 / 106.27 | 51.16 / 1235.26 | 独立信息项，不改变工程阈值 |
| Praat：可比较帧 | 2996 | 2198 | 仅作覆盖情况记录 |
| 活跃段相对增益跨度，dB | 3.37 | 7.61 | ≤8 |
| 活跃段最小相对增益，dB | -11.37 | -9.67 | ≥-12 |
| 最大相邻采样跳变比 | 1.09 | 1.43 | ≤2.5 |

两种音高估计都出现了更大的诊断偏差，范围匹配版还减少了可比较帧；1200 音分约为一个八度。不同版本的有效帧集合不完全相同，不能把两个汇总数字当成严格配对的每帧改善量，也不能直接断言声音实际整体升降了一个八度。音色/谐波改变、音高提取误判和现有时间轴疑点尚未分离。但两条路径均未达到现有保真要求这一结论不受影响，不能放宽阈值交付。

最大相邻采样指标未报警不代表用户听到的跳变消失。Jade 标出的 a2p 时段是后续定位线索，本次未将它们冒充 vocoder_only 的已确认事件边界，也没有用工程数字代替试听。

## 本轮能说明什么

- 44.1 kHz / mono / PCM16 可以作为外部文件接口；模型的原生运算速率与交付格式可以在边界转换。
- 仅匹配配置文件的频率范围，未得到可接受的重建。这不能作为整条美化链的修复方案。
- 尚不能证明声码器配置错误、权重不可用或整个 NeuralSVB 路线无效：完整训练特征规则仍未证实，当前实验刻意没有同时改变对数刻度或 F0 对齐。
