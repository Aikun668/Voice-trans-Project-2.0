# 声码器频谱范围单项验证

授权：Jade 要求先判断 44.1 kHz / 单声道 / 16-bit PCM 接口影响，无冲突则执行第一步。只做本项，不接声学模型，不继续其他假设。

目标：验证当前 50–11025 Hz mel 直接进入配套配置为 0–8000 Hz 的声码器，是否是声音重建损伤的原因之一。

素材：test_dataset/my_singing/zuixuan_normal.wav。已确认问题为声码器版沙哑/跳变；a2p 约 2、3、9、17–19 s 有跳变，这些秒数作为对照重点，不能认定 vocoder_only 事件必在同秒。

预期：范围匹配后，重建声音更接近原音，少沙哑和跳变。否决：新增失真、嗲感、音高漂移、局部掉音或跳变。Agent 不能直接听音，工程结果不能代表该预期实现。

## 固定条件

- 声码器官方 1012 权重及实现；不加载/调用声学模型、PPG 或音色编码器。
- 使用同一官方 PWG 特征函数；保留 log10、FFT/window 512、hop 128、居中/补边默认值。只把 fmin/fmax 从 50/11025 改为 0/8000；这是“范围匹配”，不等于完整训练特征契约已证实。
- 从基线特征对应波形只提取一次 F0，两个输出共用逐元素相同曲线。暂不修正已有时间轴疑点。
- 两次声码器生成前均重置随机种子 0；不依赖旧批处理的未固定声码器种子。
- 输入和交付均为 44100 Hz / mono / PCM16 WAV；内部 22050 Hz，仅作模型运算，导出用同一重采样方法。上采样不恢复高频细节。
- 共同固定增益匹配响度，沿用 -18 LUFS / -3.1 dBTP 余量计算，不做动态限幅。

Ruling：不沿用旧的 4 帧分组裁剪——这是声学模型约束，本次不使用声学模型。保留全部 mel 帧；声码器生成后仅裁去超出原始时长的 STFT 末尾补齐部分，输出样本数须等于源文件。若生成不足，拦截而不静音填充。代价：新基线不与 v002 逐字节相同，不能声称复现旧输出；本轮两条新对照之间只有频率范围不同。
