## 输入和方法

- 三条输入：本人对照版、本人轻度版，以及原唱 WAV 的 112.8–121.1 秒候选窗口。全部从现有源文件读取，原唱窗口只在内存中截取，未写出音频。
- 复用 [Qwen3-ForcedAligner-0.6B](https://huggingface.co/Qwen/Qwen3-ForcedAligner-0.6B) 本地权重 `D:\My_Grand_Projects2026\Videos-Master-Project\Qwen3-ForcedAligner-0.6B`，本地 README 标注 Apache-2.0；使用现有 `qwen-asr`、CPU、`Qwen3ForcedAligner.align(audio, text, language)`，未安装依赖。
- `results/alignment.json` 保存模型版本、源哈希、窗口起点、原始局部时间、换算后的源文件绝对时间和逐字检查；`results/candidate_pairs.csv` 为三份结果按同字序号合并的候选对照。原唱的源文件时间已经加回 112.8 秒，不要再重复加一次。
