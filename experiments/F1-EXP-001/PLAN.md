# F1-EXP-001：单模块 EQ Baseline（Phase-2）

日期：2026-10-31。状态：pending_jade（等待用户试听）。

## 目标与边界

- 只测试一个 EQ 模块，不叠加压缩、饱和、混响、谐波增强或其他美化。
- Dev：A01、A02、A03、A05、B01、B02。
- 封存：A04、A06、B03、C03；C01、C02 不参与核心调参。
- 不根据 Holdout 效果反改参数；本轮先只跑初始参数，最多两轮有记录的优化。
- 原始音频不改；输出写入本实验新目录。

## 方案（统一参数，所有 Dev 共用）

### E1：中低频主体感

- Pedalboard LowShelfFilter：cutoff 220 Hz，gain +2.0 dB，Q 0.7。
- 依据：Phase-1 中自录薄音版 80–500 Hz 占比高、频谱偏暗；GTSinger 女A 中频占比高。测试“增加低中频主体”是否真的改善厚度，同时预计可能带来闷/糊风险；不预设增加低频有效。

### E2：中高频存在感

- Pedalboard HighShelfFilter：cutoff 3000 Hz，gain +1.5 dB，Q 0.7。
- 依据：自录薄音版频谱质心低、5–8 kHz 占比低；测试“提升清晰度/存在感”是否改善偏暗、缺乏主体感。清晰度不等于饱满度。

两个方案各自只有一只 EQ 滤波器，不叠加；不使用 high-pass、压缩、de-esser 或其他模块。

## 输出与试听

每个 Dev 样本生成 Original、E1、E2。E1/E2 未归一化结果单独保存；试听版统一响度匹配。试听页只显示“原音 / 版本 A / 版本 B”，A/B 与 E1/E2 的映射保存在盲听 key 中，不显示给试听者。

## 评价与停止

用户听感优先：饱满度、自然度、音色保留、是否更愿意听处理版。技术检查：长度/格式不变、无削波、无异常增益、无非有限值。任何单一频谱指标不能代替听感通过；用户未试听前保持 pending_jade。

若首轮无可听正向改善或出现明显副作用，停止并报告负面结论；最多两轮参数优化，不得用 Holdout 调参。
