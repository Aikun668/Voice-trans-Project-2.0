- **空响**：V1/V3 让原音字尾衰减段（相对响段 −6~−25 dB、下降 >60 dB/s）比演唱主体高 +7~+10 dB，响段只高 +1 dB。压缩 5 ms 起音 / 80 ms 释放会在每个字结束后回弹，把房间尾音放大约 3 倍。发生在句内，v002 的句间处理无效。
- **F2 漏修**：phase4/4b 只判"稳定音"，3 条跑调录音有 37–49% 的浊音时间（拖音/滑音/变口型）从未判定。
