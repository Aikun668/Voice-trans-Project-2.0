怎么听：戴耳机，先把音量调好，之后不要再动。点按钮会从当前位置无缝切换。 F1 和组合版在 -13 LUFS，F2 单独比较在 -16 LUFS。听完点最底下"生成答案"。
建议顺序：先在"F1 单独"里听平凡之路和我们的歌，从 V1 切到 A，确认空旷感有没有少；再从 A 切到 B，看力度有没有起来。
这一版改了什么
做法与依据
空旷/回音 找到了真正的原因：压缩器在每个字唱完后马上把音量回弹上来，把字尾的房间余音放大了约 3 倍。V1/V3 的字尾比原音高 +6~+8 dB，而响的地方只高 +1 dB。 这发生在句子里面，所以上一轮压句间底噪没用。
新的 A：EQ 保持你两次都选的 V1 不变；压缩改成字唱完后不急着回弹（释放 80 → 350 ms），起音不再压扁（5 → 25 ms，保留每个字的冲击）；再加"字尾守护"，字尾最多只比原音高 3 dB。 实测字尾抬升从 +6~+8 dB 降到 +2.6~+3.2 dB。
力度 B = A + 第一共振峰上移 70 Hz。这是之前 S45 的核心处理（S45 是唯一一版你说"饱满度 OK、清晰度 OK、像本人"的）。这次不再需要你的正常版做参考，4 首都能用。 共振峰上移相当于"嘴张得更开、更用力"时的口腔共鸣。代码是从 S45 原样拆出来的，能逐个采样复现 S45。
F2 拖音 发现：3 条跑调录音里有 37–49% 的演唱时间（拖音、尾音变口型、吼的段落），上一版完全没进入判断，所以几乎没修。
新版：① 对齐允许你"拖得比原唱长"；② 拖音按 0.24 秒一段跟着修，慢慢跑偏的部分会慢慢拉回，颤音保留；③ 相邻两个被修的音之间平滑过渡，不再先回到原音高再跳走。轻度版 16–19 秒的电音，很可能就是那种来回跳造成的。
④ 为了不引入电音，有 3 种情况不修：两种对齐方法给出的偏差不一致；音短于 0.25 秒；原唱那里本身就是滑音。所以严重版里你故意吼、故意变口型的尾音，很多会保持原样。

一、F1 单独：4 首薄音版

二、F2 单独：只改音高（等响）

三、组合：F2 修音 → F1
