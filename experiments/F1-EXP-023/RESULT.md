# F1-EXP-023 结果（pending_jade）

F1-P9 选择性向上动态处理：基线 EXP-020 S45（X1+M2+F1 最大档）。方向与 EXP-008 的向下压缩**相反**——只抬低于正常水平的弱段，强段不动。

## 算法

- 参考电平 R = 浊音帧能量 P75 = **−17.84 dB**
- 死区 3dB：只有低出 3dB 以上才处理
- 增益 = min(GMAX, RATIO_UP × 缺口)，平滑 attack 20ms / release 30ms
- 非浊音帧目标增益为 0（不抬气声/静音）

## 两档结果（大跨度）

| 项 | U1（温和） | U2（激进） |
|---|---|---|
| RATIO_UP | 0.35 | **1.00（完全填平）** |
| GMAX | 6 dB | **20 dB** |
| **弱段中位增益** | **+1.25 dB** | **+3.63 dB** |
| **弱段 P90 增益** | **+5.50 dB** | **+17.40 dB** |
| 中间段增益 | +0.01 dB | +0.02 dB |
| **强段增益** | **+0.03 dB** | **+0.09 dB** |
| 有效抬升（≥1dB）覆盖 | 24.6% 帧 | 39.5% 帧 |
| F0 中值 | 176.39 Hz | 176.76 Hz |
| crest | 16.73 | 16.28（动态确有收窄） |
| 削波 | 0 | 0 |
| 统一响度 | −19.97 LUFS | 同 |

**关键：强段增益 0.03 / 0.09 dB，几乎完全未动**——确认这是"选择性抬弱"，不是整体增益。

**跨度验证**：两档弱段 P90 差 **11.9 dB**，中位差 2.4dB，足以听出差别。

## 处理过程中修复的一个问题（记录在案）

首轮 release 设为 60ms，导致强段落入 +0.67dB 残留泄漏（被判 hard fail）。查明原因：强弱交界处增益衰减需约 60ms，强段较短时无法回落。**缩短 release 到 30ms 后泄漏降至 0.09dB**，非放宽阈值。

## 局限

- 参考电平用浊音帧 P75，是工程近似，不等于"应该有多响"；
- 抬升无法区分"虚"（气声多）与"弱"（力度低），弱段里的气声会同比放大；
- U2 弱段 P90 达 +17.4dB，可能出现"突然变实"的突兀感或抽吸，属高风险档，已在试听页标注；
- 自实现机制未与外部工具校验；Agent 未听音。

## 边界

未改 F0、节奏、时长；未加 EQ/饱和/谐波模块；Holdout 未处理；原素材未改动。
