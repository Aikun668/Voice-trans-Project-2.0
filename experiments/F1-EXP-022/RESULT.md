F1-P8 薄 B 局部动态下陷诊断：4 对自录（薄音版 / 正常版），统一响度 −20 LUFS 后分析，两尺度局部基准（1.2s / 3.0s 窗 P75）。

## 解释（关键）

薄音版的能量分布不是"持续偏弱"，而是**"稳定段更稳、但会突然深度塌陷"**：

- 浊音段能量标准差反而更小（3/4）→ 稳定段是平的；
- 中等幅度下陷更少（4/4）→ 没有持续的小幅波动；
- **但深度塌陷是正常版的 1.6–2.9 倍（4/4）**。

这与用户原话高度吻合："**唱着唱着**（稳定段）**掉下去**（深度塌陷）**更轻了**"。

## 不确定性（必须说明）

1. **深度下陷（>12dB）的性质未定**：可能是元音尾部自然变虚、也可能是字间/句间间隙、或浊音判据在低能量处的误判。本轮未区分"发生在元音开头/中间（不自然）"与"发生在结尾（自然衰减）"。
2. **中等下陷结论是反向的**，说明"薄 B = 更多局部下陷"的原始表述不成立；成立的只是"深度塌陷更多"这个子命题。
3. DTW 对齐相关系数 0.985–0.999（见 CSV），确认两版确在唱同一段。
4. 局部基准取 ±600ms / ±1.5s 的浊音帧 P75，是"乐句正常水平"的近似，不等于真实乐句切分。

## 决策建议

- **4/4 一致，且有听感对应** → 可建议开展选择性向上动态处理实验；
- 但必须先确认深度塌陷的位置性质，否则会把"自然收尾"也填平，产生"每个字一样重"的副作用；
- 若用户核对后认为这些位置属于正常演唱表现，则应停止向上压缩方向。
