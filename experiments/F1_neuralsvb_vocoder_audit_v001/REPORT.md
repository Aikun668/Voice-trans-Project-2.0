- 声码器 1012 配置：fmin 0 / fmax 8000、use_pitch_embed=true（NSF 谐波源，直接吃 Hz 的 F0）。声学模型 1030：fmin 50 / fmax 11025。官方仓库把后者的 mel 直接送入前者。

## 声学指标（Praat，描述性，不是听感）
见 voice_quality.json。三条素材、原音/仅声码器/完整美化：
- HNR 中位数：仅声码器比原音高 1.9–2.8 dB；a2p 高 3.9–6.9 dB。jitter、shimmer 都更低。
- 有声帧数：仅声码器保持原音的约 97–99%；a2p 减少：SHIGE 1383→1285（-7%）、zuixuan 2123→1849（-13%）、茉莉花不减。
- 解读：输出比原音更“周期、干净”，没有出现“噪声增多/谐波变弱”那种典型沙哑的指标特征。指标没有复现沙哑听感，也区分不开“茉莉花可以”和“SHIGE/zuixuan 不行”。
- a2p 的有声帧缩减恰与 Jade 觉得有问题的两条素材对应（zuixuan 最多），是路线 3 的线索，未证明因果。
