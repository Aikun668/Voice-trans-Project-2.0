# F1-EXP-015 结果（weak_positive_escalate）

修复 EXP-014 的相位抵消缺陷：增益表改为整段统一（每帧掩膜形状一致），覆盖仍为 H1–H23。两档唯一差别 = 是否允许降低基频。

- 交付：X1, X2（盲听 A=X1, B=X2）
- 技术失败：无；工程标记：X1, X2（H18 增益 8.96dB 触顶提示）
- 客观对齐：X1 的 H1−H2 5.79（目标 5.38）、丰富度 −19.62（目标 −19.45）、频谱重心 404Hz（目标 403Hz）——谐波结构与重心几乎完全对齐
- 实际增量：500–1000Hz +3.82dB、1000–2000Hz +5.14dB（EXP-014 坏版本分别只有 +0.17 / −1.66）

## 归档判定

- 弱正向且方向对（首次同时出现"更饱满"反馈），但强度未达"正常试听即可感知"线。
- **重心假设的直接反证**：X1 重心 404 vs X2 重心 361（相差 43Hz），用户听不出 A/B 差别 → 频谱重心本身不是感知瓶颈；且 X1 重心已与正常版一致（404 vs 403），重心没有"没动"的问题。
- 需求升级（用户明示）：目标从"调出效果"改为"调到一听就能听出来"。
- 下一步（F1-EXP-016）：在 X1 基线上补宽带 2–8kHz 频谱强调——按实测剩余缺口，这是唯一未被谐波对齐覆盖的大块。
