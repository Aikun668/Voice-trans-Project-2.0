## 三档含义（务必分清）

| 文件后缀 | 中文名 | 是什么 |
|---|---|---|
| _micro_off | **对照微微跑调** | 词基本对、整体接近正常，但**故意留一点点跑调**；不是干净 normal，也不是 mild |
| _mild | 轻度跑调 | 明显有几处长音停错 |
| _severe | 严重/重度跑调 | 更多错音或整段偏音 |

不要把 _micro_off 当成「完美对照 / 零跑调」。听感对比时：它是「微微跑」锚点，真正干净对照没有单独一条。
