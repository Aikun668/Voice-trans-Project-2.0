## 三档含义（务必分清）

| 文件名里的档位 | 含义 |
|---|---|
| **对照微微跑调** | 词基本对、整体接近正常，但**故意留一点点跑调**；不是干净 normal，也不是轻度 |
| **轻度跑调** | 明显有几处长音停错 |
| **严重跑调** | 更多错音或整段偏音（原「重度」并入此档） |

不要把「对照微微跑调」当成完美零跑调对照。
